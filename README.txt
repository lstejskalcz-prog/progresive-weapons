ProgressiveWeapons 1.0.1 - source project

IMPORTANT: This ZIP is NOT an installable Minecraft plugin.
Compile using JDK 25 and Maven: mvn clean package
Or run build-windows.bat (requires JDK 25 and Maven installed).
Alternatively upload project contents to a GitHub repository and run the included GitHub Actions workflow.
The compiled plugin will be target/ProgressiveWeapons-1.0.1.jar.
Copy ONLY that compiled JAR to the Paper server plugins directory.
Paper API: 26.2-R0.1-SNAPSHOT.
Note: Compilation and runtime could not be tested in this environment (no JDK 25 or Paper API available).
